# Бот-генератор ссылок в закрытые каналы и группы

Юзер жмёт кнопку в меню и получает **личную** инвайт-ссылку. Она либо одноразовая,
либо «по заявке» (бот сам одобряет только того, кому выдал ссылку).
Всё управление — через `/admin` на кнопках.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и ADMIN_IDS
python -m bot
```

## Как подключить чат к кнопке

1. `/admin` → 🔘 Кнопки → ➕ Новая кнопка → название.
2. Бот покажет «➕ Добавить в канал» / «➕ Добавить в группу» — право
   «Приглашать пользователей» там уже отмечено. Выбери чат.
3. Бот сам привяжется к этой кнопке и напишет «✅ Кнопка теперь ведёт в …».

Если бот уже админ в нужном чате — «📋 Выбрать из подключённых».

## Если чат снесли или бота выкинули

Кнопка помечается ⚠️, юзеры видят «временно недоступно», админам приходит уведомление.
Чинится так: кнопка → 🔗 Заменить чат → добавить бота в новый чат. Кнопка остаётся той же,
старые ссылки отзываются, статистика сохраняется.

## Ссылки

- **Одноразовая** — `member_limit=1`, сгорает после первого входа.
- **По заявке** — юзер отправляет заявку, бот одобряет только владельца ссылки
  (отключается в ⚙️ Настройках).
- **Срок жизни** — без срока / 15 мин / 1 ч / 6 ч / 24 ч.
- Повторное нажатие отдаёт ту же живую ссылку, а не плодит новые.
- После входа ссылка сразу отзывается, неиспользованные чистятся автоочисткой.
- «🗑 Отозвать ссылки» — отзывает все неиспользованные ссылки кнопки разом.

Telegram не даёт боту полностью стереть ссылку — только отозвать. Отозванные лежат
в разделе «Отозванные» в настройках чата, оттуда их можно удалить вручную.

## Приветствие

Текст или фото/видео/GIF/файл с подписью, форматирование сохраняется.
Плейсхолдеры: `{name}`, `{full_name}`, `{username}`, `{mention}`, `{id}`.

## Структура

```
bot/
  __main__.py          запуск, middleware учёта юзеров
  config.py            .env
  db.py                SQLite: users, admins, chats, buttons, invite_links, joins, settings
  texts.py             тексты и плейсхолдеры
  handlers/
    user.py            /start, выдача ссылок
    admin.py           админка
    chat_events.py     добавление/удаление бота, вступления, заявки, миграция групп
  services/
    invites.py         создание/отзыв ссылок, привязка, автоочистка
    menu.py            приветствие и меню
    notify.py          уведомления админам
```
