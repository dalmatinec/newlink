# Бот-пересыльщик (поддержка через группу)

Простой бот без меню и форм: всё, что пишет пользователь, пересылается
в группу поддержки, а ответы из группы (реплаем) уходят пользователю.

## Как работает

1. Пользователь жмёт **/start** — бот пересылает это сообщение в группу
   и отвечает приветствием.
2. Пользователь пишет текст — бот **пересылает (forward)** его в группу.
   Принимается **только текст**; фото, стикеры, голосовые и т.п. отклоняются.
3. Любой участник группы отвечает **реплаем** на пересланное сообщение —
   пользователь получает:

   ```
   💬 Ответил @username:

   текст ответа
   ```

   Если у ответившего нет username — вместо него его ID.
4. Переписка бесконечная в обе стороны. Реплай на ответ коллеги в группе
   тоже уходит тому же пользователю. Доставленный ответ бот отмечает 👍,
   если пользователь заблокировал бота — пишет об этом в группу.

### Ограничения

- **Пользователь (ЛС):** антифлуд (N сообщений за T секунд → мут),
  антиспам (повтор одного и того же текста, лимит длины), только текст,
  бан.
- **Группа поддержки:** никаких лимитов — отвечать можно сколько угодно,
  в группе можно отвечать и медиа (фото, файлы, голосовые и т.д.).

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
export SUPER_ADMIN_ID="ваш_telegram_id"   # можно несколько через запятую
python main.py
```

Дальше:

1. Добавьте бота в группу и **сделайте его администратором**
   (иначе Telegram не покажет ему команды в группе).
2. Напишите в группе `/setgroup` — она станет группой поддержки.

## Команды админа

| Команда | Что делает |
|---|---|
| `/admin`, `/help` | список команд |
| `/setgroup` | в группе — сделать её группой поддержки |
| `/setgroup -100…` | то же из ЛС по id |
| `/group` | текущая группа |
| `/texts` | все тексты с ключами |
| `/settext ключ текст` | изменить текст (форматирование Telegram сохраняется); реплаем на сообщение — взять текст оттуда; `-` — не отправлять |
| `/resettext ключ` | вернуть текст по умолчанию |
| `/settings` | лимиты антифлуда |
| `/set ключ число` | изменить лимит |
| `/stats` | число пользователей |
| `/admins`, `/addadmin id`, `/deladmin id` | управление админами |

Для всех участников группы поддержки (и админов):

| Команда | Что делает |
|---|---|
| `/ban`, `/unban` | реплаем на сообщение пользователя или с id |
| `/info` | кто это: id, имя, username, ссылка на профиль |

### Ключи текстов

`start` (переменная `{name}`), `sent`, `only_text`, `flood` (`{seconds}`),
`duplicate`, `too_long` (`{max}`), `banned`, `unavailable`,
`reply` (`{who}` — @username или ID ответившего, `{text}` — ответ).

### Ключи лимитов

`flood_limit`, `flood_window`, `flood_mute`, `duplicate_window`, `max_length`.

## Структура

```
main.py                    запуск, подключение роутеров
config.py                  токен, главные админы, путь к БД
database.py                SQLite: пользователи, связки сообщений, тексты, настройки
utils.py                   проверка админа, подстановка текстов
middlewares/antiflood.py   антифлуд/антиспам (только ЛС)
handlers/admin.py          команды админа
handlers/group.py          ответы из группы → пользователю
handlers/user.py           сообщения пользователя → в группу
```
