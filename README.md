# Бот-пересыльщик (поддержка через группу)

Простой бот без меню и форм: всё, что пишет пользователь, пересылается
в группу поддержки, а ответы из группы (реплаем) уходят пользователю.

## Как работает

1. Пользователь жмёт **/start** — бот пересылает это сообщение в группу
   и отвечает приветствием.
2. Пользователь пишет текст — бот **пересылает (forward)** его в группу.
   Принимается **только текст**; фото, стикеры, голосовые и т.п. отклоняются.
3. Любой участник группы отвечает **реплаем** на пересланное сообщение —
   пользователь получает:

   ```
   💬 Ответил @username:

   текст ответа
   ```

   Если у ответившего нет username — вместо него его ID.
4. Переписка бесконечная в обе стороны. Реплай на ответ коллеги в группе
   тоже уходит тому же пользователю. Доставленный ответ бот отмечает 👍,
   если пользователь заблокировал бота — пишет об этом в группу.

### Ограничения

- **Пользователь (ЛС):** антифлуд (N сообщений за T секунд → мут),
  антиспам (повтор одного и того же текста, лимит длины), только текст,
  бан.
- **Группа поддержки:** никаких лимитов — отвечать можно сколько угодно,
  в группе можно отвечать и медиа (фото, файлы, голосовые и т.д.).

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
export SUPER_ADMIN_ID="ваш_telegram_id"   # можно несколько через запятую
python main.py
```

Дальше:

1. Добавьте бота в группу и **сделайте его администратором**
   (иначе Telegram не покажет ему команды в группе).
2. Напишите в группе `/setgroup` — она станет группой поддержки
   (или укажите id группы в `/admin` → «Группа»).

## Админ-панель

`/admin` в личке с ботом открывает инлайн-панель (только для админов):

- **👥 Группа** — текущая группа поддержки, смена по id
  (или `/setgroup` прямо в группе).
- **✏️ Тексты** — все тексты бота: изменить (форматирование и premium-эмодзи
  сохраняются), «не отправлять», вернуть по умолчанию.
- **🛡 Антифлуд** — лимиты для пользователей: сообщений за окно, окно,
  мут, повтор текста, максимальная длина.
- **📣 Реклама** — 10 слотов и общий выключатель. В слоте: контент
  (форвард поста или текст/фото/видео/GIF/документ/голосовое/кружок/стикер),
  кнопки-ссылки, расписание, вкл/выкл, превью, очистка.
  Расписание: «каждый /start», «один раз», «раз в N часов», «N раз в сутки»
  (последние три — при любом сообщении пользователя). За раз показывается
  не больше одной рекламы.
- **🚫 Баны** — забанить по id / пересланному сообщению, список с разбаном.
- **📊 Статистика** — пользователи (всего, новые, активные, в бане),
  сообщения и ответы за сегодня / 7 дней.
- **👮 Админы** — список; добавлять и удалять может только главный
  админ (`SUPER_ADMIN_ID`).

В группе поддержки для всех её участников:

| Команда | Что делает |
|---|---|
| `/ban`, `/unban` | реплаем на сообщение пользователя или с id |
| `/info` | кто это: id, имя, username, ссылка на профиль |
| `/setgroup` | (админ) сделать эту группу группой поддержки |

## База данных

SQLite (WAL). Индексы:

- `users(first_seen_at)`, `users(last_seen_at)` — статистика новых/активных;
- частичный `users WHERE is_banned = 1` — список банов;
- `message_map(user_id)` — сообщения конкретного пользователя;
- `ad_shows(slot_id)` — сброс показов при смене рекламы;
- частичный `ads WHERE enabled = 1` — выбор включённых слотов на каждое сообщение.

`bot.db` от старой версии бота подхватывается: недостающие колонки
добавляются автоматически.

## Структура

```
main.py                    запуск, подключение роутеров
config.py                  токен, главные админы, путь к БД
database.py                SQLite: пользователи, связки сообщений, тексты, настройки, реклама, индексы
utils.py                   проверка админа, подстановка текстов
middlewares/antiflood.py   антифлуд/антиспам (только ЛС)
handlers/panel.py          инлайн-админка (/admin)
handlers/admin.py          команды в группе (/ban, /unban, /info, /setgroup)
services/ads.py            реклама: расписание, отправка, разбор кнопок
handlers/group.py          ответы из группы → пользователю
handlers/user.py           сообщения пользователя → в группу
```
