# LinkHub X — часть 1 (без системы клонов)

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен_от_BotFather"
export SUPER_ADMIN_ID="ваш_telegram_id"
python main.py
```

Все настройки, кроме токена/id/пути к БД, живут в `texts.json`, `links.json`,
`ads.json`, `settings.json` и правятся прямо через inline-админку (`/admin`),
без перезапуска бота и без правки кода.

## Что уже работает

- Главное меню на основе `links.json`: кнопки любых типов (url, generated,
  menu, callback, webapp, copy, share), любые ряды, конструктор через
  `/admin` → «🔗 Кнопки и меню» (добавление, удаление, перемещение в любую
  позицию любого ряда).
- Генерируемые ссылки (тип `generated`) — источник чата: форвард поста,
  `t.me/...`, `@username` или `chat_id`. Режим на каждую кнопку свой:
  «по заявке» (`creates_join_request`) или «лимит на 1 человека»
  (`member_limit=1`, ссылка сгорает после первого перехода).
- Приветствие — текст/HTML/Premium Emoji + любой тип медиа, редактируется
  через `/admin` → «👋 Приветствие».
- Реклама — 10 слотов, контент форвардом или вручную, гибкое расписание
  (каждый запуск / один раз / раз в N часов / N раз в сутки), общий
  выключатель в настройках.
- Рассылка — форвард или ручной ввод, конструктор кнопок, обязательный
  предпросмотр перед отправкой, отчёт «успешно / заблокировали / ошибки».
- Статистика — пользователи, новые за сегодня/неделю/месяц, активные,
  заблокировавшие бота, количество запусков.
- Навигация — все меню используют delete-and-send (`services/navigator.py`),
  чтобы не засорять ЛС юзера.

## Важно перед боевым запуском

- **Токен из архива утёк.** В присланном `config.py` был прописан реальный
  `TOKEN` — раз он засветился в файле, который передавался мне, лучше
  перевыпустить его через @BotFather (`/revoke`) и не использовать старый.
- **Цветные кнопки и premium-иконки на кнопках** (`style`,
  `icon_custom_emoji_id`) — это Bot API 9.4 (с 9 февраля 2026), в коде уже
  поддержаны, но `icon_custom_emoji_id` на кнопке физически отобразится,
  только если у владельца бота активен Telegram Premium либо куплены
  дополнительные юзернеймы на Fragment — иначе Telegram его просто
  проигнорирует.
- Конструктор кнопок пока управляет только меню `main` — подменю через
  кнопку типа `menu` создаются автоматически по id, но у них пока нет
  отдельного экрана в админке (только предпросмотр всего файла) — это
  следующий шаг.

## Что осознанно не в этой части

- Система клонов (заявки, автосоздание, мульти-бот в одном процессе) —
  отдельная фаза 2, чтобы сначала обкатать один бот целиком.
- Детальный трекинг кликов по каждой кнопке — по договорённости оставили
  только простые счётчики (новые/запуски по дням).
