# newlink - бот личных ссылок в закрытые каналы и группы

Человек жмёт кнопку и мгновенно получает **свою** инвайт-ссылку: одноразовую или по заявке.
После выдачи бот может показать рекламу.
**Всё настраивается в боте, командой /admin**: кнопки, чаты, тексты с премиум-эмодзи, цвета кнопок,
расположение кнопок, реклама, рассылка, админы с правами.

## Запуск

```bash
cp .env.example .env        # впишите BOT_TOKEN и OWNER_IDS
pip install -r requirements.txt
python -m bot
```

Docker: `docker compose up -d --build` (данные лежат в `./data`).

Сервер (Ubuntu/Debian, systemd):
```bash
git clone https://github.com/dalmatinec/newlink /opt/newlink
bash /opt/newlink/deploy/install.sh                  # спросит токен и ID владельца
bash /opt/newlink/deploy/install.sh /root/backup.zip # то же + восстановить всё из бэкапа
journalctl -u newlink -f                             # логи
```
Обновление: `cd /opt/newlink && git pull && systemctl restart newlink`.

## Как это выглядит для пользователя

```
/start → приветствие (текст + фото/GIF/видео) и кнопки
 └─ 🔥 VIP → отдельное сообщение: 🚀 Вступить (личная ссылка) и ✖️ Закрыть
                                                          ↳ реклама отдельным сообщением ниже
```
Главное меню всегда одно и остаётся на месте. Каждая кнопка присылает ссылку отдельным сообщением с кнопкой
✖️ Закрыть; повторное нажатие не шлёт дубль, пока прошлая ссылка жива. Сообщения пользователя удаляются.
Прямая ссылка на кнопку для постов: `t.me/<бот>?start=i5` - сразу выдаёт ссылку.

## Админка (/admin)

| Раздел | Что можно |
|---|---|
| 🔗 Кнопки | кнопка-ссылка в чат или обычная ссылка; текст, премиум-иконка, цвет; режим одноразовая / по заявке; срок жизни ссылки; статистика; отозвать ссылки |
| ↕️ Двигать кнопки | меню как у юзеров: выбрал кнопку и двигаешь стрелками, одно нажатие = один шаг. ⬆️ из ряда: своя строка выше, ещё ⬆️: в ряд выше (2-2-2 → 2-2-1-1 → 2-3-1). ⬅️ ➡️ внутри ряда |
| 🔄 Замена чата | кнопка → Заменить чат → ➕ Добавить в канал → бот сам привяжется. Кнопка та же, старые ссылки отзываются |
| 🔌 Чаты бота | новые чаты появляются сами, когда бота добавляют админом. Каждые 15 минут бот проверяет чаты, не создавая новых ссылок: удалённые и замороженные сами пропадают из списка, кнопки на них помечаются ⚠️, ожившие чаты снова работают. Кнопка Проверить сейчас |
| 📢 Реклама | переслал пост (кнопки подтянутся сами) → ▶️ Запустить. Места: после /start и после выдачи ссылки. Лимит показов, срок, частота на человека (каждый раз / раз в N часов / один раз), общая пауза между рекламами, автостоп и отчёт по дням для рекламодателя, копия объявления |
| 📣 Рассылка | любое сообщение + свои кнопки, всем / активным за 7 / 30 дней, предпросмотр, прогресс, остановка |
| 📝 Тексты и кнопки | все тексты экранов и всплывашек, системные кнопки (Вступить, Назад...). Плейсхолдеры `{имя}`, `{юзернейм}`, `{упоминание}`, `{id}`, `{кнопка}` |
| 📊 Статистика | пользователи, выдано ссылок, вступления, конверсия, топ кнопок, реклама |
| 👥 Пользователи | поиск, бан на время / навсегда |
| ⚙️ Настройки / 🛡 Защита | запас ссылок, автоочистка, заявки только от владельца, чистка чата, запрет пересылки, канал логов, антифлуд |
| 💾 Бэкап · 👮 Админы · 📜 Журнал | архив раз в сутки и по кнопке, восстановление; права админов галочками; кто что менял |

Если чат удалили или бота выкинули - кнопка помечается ⚠️, юзеры видят временно недоступно,
админам и в канал логов приходит уведомление.

Telegram не даёт ботам стирать ссылки совсем - только отзывать. Отозванные лежат в разделе
Отозванные в настройках чата, их можно удалить оттуда одной кнопкой.

## Почему быстро

- **Запас готовых ссылок.** Бот заранее держит по 5 ссылок на каждую кнопку (настраивается). Нажатие - это один запрос к базе (~2 мс), без ожидания Telegram. Запас пополняется в фоне с паузами, чтобы не
  упираться в лимиты. Пусто - ссылка создаётся на лету.
- **Всё, что видит юзер, - из памяти.** Тексты, кнопки, чаты, реклама лежат в кэше; база
  трогается только при выдаче ссылки.
- **Запись пачками.** Активность, показы рекламы и экраны пишутся в базу раз в 30 секунд одной транзакцией.
- **Индексы на каждой выборке** (проверяется тестом), SQLite в режиме WAL, `PRAGMA optimize` раз в сутки,
  старые отозванные ссылки чистятся через 30 дней.
- Отзыв ссылок - фоновой очередью, юзер его не ждёт. `uvloop`, если установлен.

## Для разработчика

```
bot/
  __main__.py        запуск, сборка приложения (setup - отдельно, для тестов)
  app.py             контейнер сервисов, буферы записи, админы, канал логов
  store.py           кэш в памяти (настройки, тексты, кнопки, чаты, реклама)
  db.py              SQLite (WAL) и миграции - новые добавлять в конец MIGRATIONS
  seed.json          тексты, кнопки и настройки по умолчанию (дозаливаются, правки не затирают)
  ui.py              клавиатуры, плейсхолдеры, показ экрана (edit / send+delete)
  services/links.py  выдача ссылок, запас, отзыв, вступления, замена чата
  services/ads.py    подбор и показ рекламы, счётчики, автостоп, отчёт
  layout.py          расположение кнопок по рядам (стрелки)
  services/broadcast.py рассылка
  handlers/user.py   пользовательская часть
  handlers/chats.py  события каналов: добавили/выкинули бота, вступления, заявки, миграция группы
  handlers/admin/    админка: core.py - движок экранов и прав, остальное - разделы
  middlewares.py     учёт пользователей, бан, антифлуд
  jobs.py            фоновые задачи, бэкап
```

Тесты - бот целиком на фейковом Telegram API: `python -m unittest -v`
